Where live reads and catalog reads differ
  • The composition root chooses the source before supplying an action's reader.
  • Supported reads use Tableau by default. --catalog selects SQLite only, without authentication or a live fallback.
  • Supported live inventory --all operations also publish a catalog generation. Ordinary bounded lists do not require SQLite.
  • Catalog refresh collects into staging, then publishes atomically. Some targeted live reads cache their observations independently.
  • Workspaces store managed files. The catalog stores observations. Neither replaces authoritative remote validation for consequential writes.
