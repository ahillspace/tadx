The effective policy comes from tadx mutation set, with TADX_ENABLE_MUTATIONS as an environment override. Check it with tadx mutation status. Supported mutations run when enabled; --preview remains read-only where available.

GATEDPREVIEW WHERE SUPPORTED
Catalog is Tableau metadata. Cache is local state. tadx catalog lists and inspects upstream databases, tables, and columns; updates descriptions and tags; and audits metadata coverage. Datasource inspection includes upstream dependencies, while schema inspection exposes field metadata and requested descriptions. tadx content label manages label attachments; tadx admin label manages shared label values and categories. The former local catalog commands now live under tadx cache, with --cache for supported local-only reads.
