    Search

    tadx search uses Tableau native content search for nonempty content terms. Admin and Pulse use dedicated live adapters. --cache reads local state only.

    Resource lists

    6

    Bounded live reads by default. --all collects matching inventory in memory, with best-effort cache persistence. Filtered collections save observations; only complete, unfiltered collections replace resource scope. --cache is local-only.

    Pull operations

    0

    Pull commands retrieve from Tableau and write managed artifacts by default. Where supported, --preview inspects the planned artifact write.

    Remote mutations

    0

    Remote writes require saved consent for the canonical server and exact site, plus managed policy permission. Check tadx mutation status --environment <alias> and tadx policy status. Supported previews stay read-only when their capability IDs are allowed.

    Two useful companions to the lifecycle CLI

    TADX manages Tableau content and local artifacts. Use MCP tools when you want an agent to query data or author in Desktop.

    Tableau MCP

    Query published data sources, inspect workbook view data and images, and explore Pulse metrics and insights. Pair it with TADX when analytical answers need to connect to content you manage through the CLI.

    Tableau Desktop Authoring MCP

    Give a compatible agent access to Tableau Desktop authoring tools to build or edit workbooks. Pair it with TADX to organize, inspect, or publish the resulting content through lifecycle commands. Requires a compatible Tableau Desktop authoring setup.

    These are separate integrations your agent environment may connect to. TADX does not call, configure, or grant access to them.

    tadx catalog inspects upstream databases, tables, and columns, updates descriptions and tags, and audits coverage. Datasource inspection includes upstream dependencies; schema inspection exposes fields and requested descriptions. tadx catalog label manages attachments; tadx admin label-value and tadx admin label-category manage definitions.
