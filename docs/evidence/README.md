# API contract evidence

These records preserve the upstream contracts and verification limits supporting TADX capabilities.
Official documentation is available without a local documentation capture:

| API family | Official documentation |
| --- | --- |
| Tableau REST API | [REST API help](https://help.tableau.com/current/api/rest_api/en-us/REST/) |
| Tableau Metadata API | [Metadata API guide](https://help.tableau.com/current/api/metadata_api/en-us/) |
| Metadata GraphQL schema | [Schema reference](https://help.tableau.com/current/api/metadata_api/en-us/reference/) |
| Tableau Pulse | [Pulse REST methods](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_pulse.htm) |

`Tableau API Documentation/` is an optional, ignored local reference directory and is absent from fresh clones.
Standard builds and automated tests do not require these captures.
Historical filenames, line numbers, hashes, and Git blob identifiers below identify the snapshots used for the recorded evidence.
They do not assert that a snapshot is available locally or matches today's official documentation.
Older snapshot filenames can differ from locally available captures.

For a missing capture, locate the named operation, type, or field in the official documentation for the relevant Tableau version.
A current documentation link does not reproduce historical evidence or establish a passing contract test or live verification.
Existing evidence levels and verification limits remain unchanged.
