# Superpowers source

These files come from the official `obra/superpowers` plugin, version 5.1.3.
The upstream project uses the MIT License in `LICENSE`.

This repository vendors only the instruction files selected by `$tadx-build` and their required supporting files.
The copied `SKILL.md` files use the name `instructions.md` so Codex does not discover them as independent skills.
Local changes replace plugin-qualified references with repository-relative paths.
