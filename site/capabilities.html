How commands behave

Search

tadx search uses Tableau native content search for nonempty content terms. Admin and Pulse use dedicated live adapters. --cache reads local state only.

Resource lists

Bounded live reads by default. --all collects matching inventory in memory, with best-effort cache persistence. Filtered collections save observations; only complete, unfiltered collections replace resource scope. --cache is local-only.

Pull operations

Pull commands retrieve from Tableau and write managed artifacts by default. Where supported, --preview inspects the planned artifact write.

Remote mutations

Remote writes require saved consent for the canonical server and exact site, plus managed policy permission. Check tadx mutation status --environment <alias> and tadx policy status. Supported previews stay read-only when their capability IDs are allowed.

Catalog is Tableau metadata.
Cache is local state.

tadx catalog inspects upstream databases, tables, and columns, updates descriptions and tags, and audits coverage. Datasource inspection includes upstream dependencies; schema inspection exposes fields and requested descriptions. tadx catalog label manages attachments; tadx admin label-value and tadx admin label-category manage definitions. Local catalog commands now live under tadx cache.

Tableau companion tools

TADX handles content lifecycle and local artifacts. Connect Tableau MCP in your agent to work with Tableau, and add the Tableau Plugin for guided workflows and authoring resources.

Tableau MCP

Published content. Query data sources and inspect workbook views on Tableau Cloud and Server. Explore Pulse metrics and insights on Tableau Cloud.

Tableau Studio. The Tableau MCP desktop build includes tools to create and edit workbooks, worksheets, dashboards, and data sources. Live authoring requires a running Tableau Studio instance with the External Client API enabled.

Tableau MCP docs Desktop authoring setup

Tableau Plugin

The plugin gives compatible agents skills for analytics, viewing Tableau content, authoring workbooks, and building data apps. Its hosted workflows use Tableau MCP to connect to your site.

It also supplies chart templates, workbook XML examples, schemas, and a validator for local workbook files.
