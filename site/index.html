Install TADX

Install the CLI and Agent Guidance together. You can also download and inspect the installer before running it.

Install TADX and Guidance

curl -fsSL https://tadx.net/install.sh | sh

Already installed? Update both

tadx update
Full installation guideWindows · macOS · Linux

Updates replace TADX-owned Guidance; keep personal additions in separate skills. Installation does not configure Tableau credentials or enable remote mutations. Run tadx to see your local setup.
