Get TADX.

One command installs the CLI and its agent Guidance together. Detected agent platforms receive the TADX and Pulse skills automatically.

Install TADX + Guidance

curl -fsSL https://tadx.net/install.sh | sh

Already installed? Update both.

tadx update

Then run tadx to see your environments, authentication setup, workspaces, and mutation policy. No remote calls are made by this overview.

Full installation guide ↗Windows · macOS · Linux

Public installation is available after the website and a release are published. Until then, use the GitHub-authenticated installation guide. TADX-managed Guidance is refreshed on every install and update; keep your additions in separate skills.
