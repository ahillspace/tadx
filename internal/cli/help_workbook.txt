Usage: tadx content workbook <verb> [flags]

Shared:
  --environment (--env,-e) <name> (reads: default; writes: sole configured env)
  --config <path>  --json  --full (details, not rows)

Target (remote, exact):
  --id <luid> | (--name <name> --project (--prj) <path>)

Options:
  --cache (local only; default: live)
  --preview (no writes; mutation gate can be off)
  --workspace (--ws,-w) <name> (registered; default: directory > env > global; else required)

Source (publish):
  --artifact <artifacts/workbook/item> | --file <file.twb|file.twbx>
  | --id <luid> | --artifact-name (--arn) <name>
  Workspace-relative artifact; ID/unique name: workspace item.

Commands:
  delete: target [--preview]
  inspect: target [--cache] (fetch details)
  list:
    [--name <name>] [--owner <name>]
    [--project-name <leaf>] [--tag <tag>] (exact filters)
    [--limit <1..10000> | --all] (default limit: 25) [--cache]

  move: target [--preview]
    (--destination-project-id (--dpi) <luid> | --destination-project (--dpj) <path>)

  publish: source (local to Tableau)
    (--project-id (--pid) <luid> | --project <path>) (destination)
    [--name <name>] (default: source) [--overwrite]
    [--workspace <name>] [--preview]

  pull: --id <luid> | (--name <name> [--project <path>]) (download local files)
    [--workspace <name>] [--overwrite] (dirty local files) [--preview]
    [--include-extract=<true|false>] (default: true)
    [--include-pds] (direct published datasources; siblings, no recursion)

  update: target
    [--new-name <name>] [--owner-id <luid>] [--description <text>]
    (one required; omitted unchanged; empty description clears) [--preview]

Rules:
  Remote writes require enabled mutations.
  Ambiguous names fail; project paths use /.
  publish: creates by default; --overwrite replaces the exact remote collision.
  list --all: <=10000; incomplete/overflow fails; live can save cache.

Batch:
  Repeat one selector OR use --batch-file (--btf) <path>.
    id: delete, move, update
    id | name: inspect, pull
    source: publish (repeated artifact excludes name)
  JSON: {"items":[{"id":"<luid>"}]}
  Rows: flag keys; lists use arrays; rows override CLI; required per row.
  Env/control flags outside rows.
  Limits: 1-100 sequential items; file <=1MiB; <=100 selections.

Examples:
  tadx content workbook publish --file x.twb --project Ops --preview
