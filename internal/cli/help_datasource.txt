Usage: tadx content datasource <verb> [flags]

Shared:
  --environment (--env,-e) <name> (reads: default; writes: sole configured env)
  --config <path>
  --json
  --full (details, not rows)

Target (remote, exact):
  --id <luid>
  | (--name <name> --project (--prj) <path>)

Options:
  --cache (local only; default: live)
  --preview (no writes; mutation gate may be off)
  --workspace (--ws,-w) <name> (registered; directory > env > global)

Source (publish):
  --artifact <artifacts/datasource/item>
  | --file <file.tds|file.tdsx>
  | --id <luid>
  | --artifact-name (--arn) <name>
  ID/unique name: workspace item.

Commands:
  delete: target [--preview]

  inspect: target [--cache]

  list:
    [--name <name>] [--owner <name>]
    [--project-name <leaf>] [--type <provider>] [--tag <tag>]
    [--updated-after <RFC3339>] [--updated-before <RFC3339>]
    [--limit <1..10000> | --all] (default limit: 25)
    [--cache]
    Filters: exact; timestamps inclusive UTC.

  move: target
    (--destination-project-id (--dpi) <luid> | --destination-project (--dpj) <path>)
    [--preview]

  publish: source
    (--project-id (--pid) <luid> | --project <path>) (destination)
    (--create | --overwrite | --append | --replace)
    [--name <name>] (default: source)
    [--workspace <name>] [--as-job] (waits) [--preview]

  pull: target
    [--workspace <name>] [--overwrite] (dirty local files) [--preview]

  schema: (fields/tables) --id <luid>
    [--query <text>]
      Case-insensitive substring: ID/name/caption/label/formula.
    [--role <measure|dimension|date|excluded>]
    [--table <caption>] [--field-id <id>...]
    [--limit <1..10000> | --all] (default limit: 20)
    [--descriptions] [--tags] [--cache]

  update: target
    [--new-name <name>] [--owner-id <luid>]
    (one required; omitted unchanged) [--preview]

Rules:
  Remote writes require enabled mutations.

  publish: create = collision fails; overwrite = replace collision;
           append/replace = data.

  schema: Field IDs repeat <=10000; must match filters; table disambiguates.
          Descriptions inherited; tags from upstream columns; both include sources.
          Cache needs prior observations.

  list --all: incomplete/overflow fails; may save cache.

Batch:
  Repeat one selector OR use --batch-file (--btf) <path>.

  Repeated selectors:
    id         delete, move, schema, update
    id | name  inspect, pull
    source     publish (repeated artifact excludes name)

  JSON:
    {"items":[{"id":"<luid>"}]}

  Rows: flag keys; lists use arrays; rows override CLI; required per row.
  Env/control flags outside rows.
  Limits: 1-100 sequential items; <=1MiB/100 selections.

Examples:
  tadx content datasource publish --file x.tds --project Ops --create --preview
  tadx content datasource schema --id <luid> --role measure
