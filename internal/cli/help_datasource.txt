Usage: tadx content datasource <verb> [flags]

Shared:
  --environment (--env,-e) <name> (read default; writes: configured)
  --config <path> --json --full (details, not rows)

Target (remote, exact):
  --id <luid> | (--name <name> --project (--prj) <path>)

Options:
  --cache (local only; default: live)
  --preview (no writes; mutation gate can be off)
  --workspace (--ws,-w) <name> (default: directory > env > global)

Source (publish): --artifact <artifacts/datasource/item> | --file <file.tds|file.tdsx>
  | --id <luid> | --artifact-name (--arn) <name>

Commands:
  delete: target [--preview]
  inspect: target [--cache] (fetch details)
  list: [--name <name>] [--owner <name>] [--project-name <leaf>] [--type <provider>] [--tag <tag>]
    [--updated-after <RFC3339>] [--updated-before <RFC3339>] [--limit <1..10000> | --all] (default limit: 25) [--cache]

  move: target [--preview]
    --destination-project-id <luid> | --destination-project <path>

  publish: source (local to Tableau)
    --project-id (--pid) <luid> | --project <path> (destination)
    (--create|--overwrite|--append|--replace) [--name <name>] (default: source)
    [--workspace <name>] [--preview] [--no-wait]

  pull: target (download local files)
    [--workspace <name>] [--overwrite] (dirty local files) [--preview] [--no-wait]

  schema: --id <luid> (tables/fields)
    [--query <text>] (ID/name/caption/label/formula)
    [--role <measure|dimension|date|excluded>]
    [--table <caption>] [--field-id <id>...]
    [--limit <1..10000> | --all] (default limit: 20) fields
    [--descriptions] [--tags] [--cache]

  update: target
    [--new-name <name>] [--owner-id <luid>]
    (one required; omitted unchanged) [--preview]

Rules:
  Remote writes require enabled mutations.
  Ambiguous names fail; project paths use /.
  publish: create = collision fails; overwrite replaces collision;
           append/replace = data in exact collision.
  publish: --no-wait returns one local check-status command without polling remote jobs.
           Default checks: 2s/30s, 5s/10m, then 15s to 20m; work continues after cutoff.
  pull: --no-wait returns one check-status command; downloads have no jobs to poll. Default waits through 20m; work continues after cutoff.
  schema: Field IDs repeat <=10000; match filters.
          Descriptions/tags include sources; cache needs prior.
          --all: <=10000 fields; overflow fails.

Batch:
  Repeat one selector OR use --batch-file (--btf) <path>.
    id: delete, move, schema, update
    id | name: inspect, pull
    source: publish (repeated artifact excludes name)
  JSON: {"items":[{"id":"<luid>"}]}
  Rows: flag keys; lists use arrays; rows override CLI; required per row.
  Env/control flags outside rows.
  Limits: 1-100 sequential items; file <=1MiB; <=100 selections.
  Publish/pull batches return one aggregate check-status command: queued, accepted, completed, failed, skipped, unknown.

Examples:
  tadx content datasource publish --file x.tds --project Ops --create --preview
